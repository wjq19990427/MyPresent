# Task-52：待办完成弹窗补充终止时间

## 变更说明

**类型**：Bug 修复  
待办勾选完成后弹出的时间填写窗口只能填起始时间，无法记录结束时间，导致日常事务数据不完整。补充终止时间输入，格式与起始时间完全对称。

---

## 问题描述

- **现象**：`_render_completion_activity_box()` 弹窗中仅有起始时间选择，`daily_activities.end_time` 始终为空。
- **预期**：弹窗同时展示起始时间和终止时间，两者均采用小时/分钟分开选的形式（即复用现有 `_render_time_select()` 的交互模式）。
- **涉及文件**：`components/tab_planning.py`

---

## 行为约束

- 终止时间**可选**，允许留空（留空时 `end_time` 写 `None`）。
- 若终止时间已填写，必须 ≥ 起始时间；否则阻止提交并给出提示。
- 时长计算（现有 `_duration_between()`）在终止时间有效时自动显示，留空时不显示。

---

## 验收（用户可见）

- [ ] 完成弹窗出现起始时间和终止时间两个独立的时间选择区域
- [ ] 两个时间区域均为小时、分钟分开选择，样式一致
- [ ] 终止时间留空可正常提交
- [ ] 终止时间 < 起始时间时提交被阻止，并有明确提示
- [ ] 有效填写终止时间后，自动显示时长
