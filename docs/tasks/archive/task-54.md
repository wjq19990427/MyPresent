# Task-54：已完成事务支持编辑

## 变更说明

**类型**：新功能  
已完成事务列表的每条记录目前只能删除，无法修改内容。补充编辑功能，使用户可以修正事务描述、分类、时间段和时长。

---

## 数据层

**`core/db_manager.py`**

新增 `update_daily_activity()` 公开接口，支持对 `daily_activities` 表中任意字段的更新（至少覆盖：`description`、`category`、`duration`、`start_time`、`end_time`）。

---

## UI 层

**`components/tab_planning.py`**

在 `_render_activity_row()` 中补充编辑入口和编辑表单：

- 每条事务行新增"编辑"按钮，点击后在行内展开编辑表单（行内展开或弹窗，样式参考同文件待办编辑的现有实现）。
- 编辑表单字段：描述（文本）、分类、起始时间、终止时间、时长。时间字段复用现有 `_render_time_select()` 交互。
- 终止时间若填写，须 ≥ 起始时间（与 task-52 约束一致）；可留空。
- 提交后调用 `update_daily_activity()`，刷新视图。
- 取消按钮关闭表单，不写入任何变更。

**`core/state.py`**

新增编辑展开状态的 session_state 键（键名由 Codex 决定，参考现有 `_todo_editing_*` 的动态键模式）。

---

## 验收（用户可见）

- [ ] 每条已完成事务旁出现编辑按钮
- [ ] 点击后展开编辑表单，字段预填当前值
- [ ] 可修改描述、分类、时间段、时长并保存
- [ ] 取消不影响原数据
- [ ] 终止时间 < 起始时间时提交被阻止并提示
