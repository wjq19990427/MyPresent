# API 契约填写模板

> 复制下面的 block 到对应模块 L2 文件中。每个公开 API 一份。

---

## `module.function_name(args) -> ReturnType`

- **用途**：一句话说明做什么（不是怎么做）
- **参数**：
  - `arg1` (`type`)：含义 / 取值范围
- **返回**：结构 + 字段含义
- **副作用**：写库 / 调网 / 落盘 / 修改 `session_state` / 修改全局
- **异常**：可能抛什么、什么时候抛
- **不变量**：调用方需保证 / 函数承诺
- **已知陷阱**：（可选）容易踩坑的边界

---

## 编写原则

1. 写**契约**，不写**实现**——签名变化频率远低于实现，文档不易腐
2. 不贴大段代码片段，只给签名
3. "副作用"必填——纯函数也要明确写「无副作用」
4. 私有函数（`_xxx`）不写入此文档
